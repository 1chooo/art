This journal is a quiet place for longer thoughts — typography-first, bilingual, and deliberately split between two moods: a **brutalist bento home** and an **editorial reading experience** for posts.

The home grid is loud with structure; the articles are calm with words. That contrast is intentional. This guide walks through both the why and the how.

## Step-by-step build

<Steps>
  <Step title="Scaffold Next.js + Tailwind v4">
    Start with `create-next-app` using the App Router and TypeScript. Add Tailwind v4 via `@tailwindcss/postcss` and define semantic color tokens in `globals.css` — `paper`, `ink`, `accent` for posts, and `bento-bg`, `bento-ink` for the home grid.
  </Step>
  <Step title="Wire MDX with remark-gfm">
    Install `@next/mdx`, `@mdx-js/react`, and `remark-gfm`. Wrap your Next config with `createMDX({ options: { remarkPlugins: ['remark-gfm'] } })` and add `mdx` to `pageExtensions`. Style markdown elements globally in `mdx-components.tsx`.
  </Step>
  <Step title="Add next-intl for bilingual routing">
    Configure locales (`en`, `zh`) with `localePrefix: 'always'` so every URL is prefixed. Put UI strings in `messages/en.json` and `messages/zh.json`. Use `@/i18n/navigation` for locale-aware links throughout the app.
  </Step>
  <Step title="Create a post (MDX + registry)">
    Each article lives in `content/posts/`. Export a `postMeta` object with title, date, description, and optional tags. Register the import in `lib/posts.ts` — this manual registry keeps types tight and build output predictable.
  </Step>
  <Step title="Style with prose-blog and the bento grid">
    Posts use the `@tailwindcss/typography` plugin via a custom `prose-blog` utility. The home page composes a 12-column bento grid with carousels for images, tags, and upcoming posts — all server-rendered except the carousel controls.
  </Step>
</Steps>

## Try it yourself

Here is the shape of a new post:

<CodeBlock
  title="content/posts/my-post.mdx"
  language="mdx"
  code={`export const postMeta = {
  title: "My first note",
  date: "2026-06-06",
  description: "A short summary for listings and SEO.",
  tags: ["journal"],
};

Your MDX content starts here.`}
/>

Register it in the post registry:

<CodeBlock
  title="lib/posts.ts"
  language="typescript"
  code={`import MyPost, { postMeta as metaMyPost } from "@/content/posts/my-post.mdx";

const ENTRIES: PostEntry[] = [
  {
    slug: "my-post",
    locales: { en: { meta: metaMyPost, MDXContent: MyPost } },
  },
  // ...existing entries
];`}
/>

Then run the dev server:

<CodeBlock
  title="Terminal"
  language="bash"
  code="npm run dev"
/>

Visit `/en/posts/my-post` to see it live.

## Tags and discovery
